# 4'-6" POS Cart — Interactive 3D Model

An interactive, parametric 3D model of the IKONIQ 4'-6" P.O.S Cart, built to the
shop-drawing dimensions (54" × 30" footprint, 34" counter height).

**Live model:** open the GitHub Pages link for this repo.

Drag to orbit · scroll to zoom · right-drag to pan. Buttons switch between
Front / Rear / Iso / Top views and toggle auto-spin.

### Parts modeled (from drawing legend)
1. 3" heavy-duty casters (×4)
2. Steel-tube toekick (black)
3. Alucobond base wrap (black) with vinyl-graphic band
4. Densetec countertop
5. Adjustable undercounter shelf
6. Outlet grommets (×2)
- Two POS terminals

> Visualization model for client approval and as a modeling reference — not a
> fabrication-grade CAD solid (no weld joints, wall thicknesses, or BOM).

Built with [three.js](https://threejs.org/) (loaded via CDN).
